# Play Store listing assets

Upload these in Google Play Console → Main store listing:

| File | Play Console field |
|------|--------------------|
| `play_icon_512.png` | High-res icon (512×512) |
| `feature_graphic_1024x500.png` | Feature graphic (1024×500) |
| `screenshot_phone_1.png` | Phone screenshot (replace with real device captures before production) |

Copy listing text from `app/src/main/res/values/strings.xml`:

- `store_short_description`
- `store_full_description`

Privacy policy URL (after GitHub Pages is enabled on `main`):

`https://victormart43210-ship-it.github.io/CoreGuard-Android/privacy-policy.html`

Subscription product ID (create in Play Console → Monetize):

`coreguard_premium_monthly`
